# Design Task & VM Build Protocol

## Directives
1. **Do NOT build/run apps in this VM**: Do not start dev servers (`npm run dev`, `next dev`, background daemons, etc.) inside this VM environment unless specifically asked.
2. **Design Tasks**: When the user asks for a design task, always use `desighn.md` provided by the user. If `desighn.md` has not been provided by the user, **ask first** for `desighn.md` before proceeding with the design task.
